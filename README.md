# 📄 ResumeCraft.ai

An AI-powered resume tailoring and optimization application that helps job seekers customize their resumes for specific job descriptions instantly using Google's Gemini API.

---

## ✨ Features

* 🤖 **AI Resume Tailoring**: Automatically aligns your resume skills, experience, and summary with job requirements using Gemini AI.
* 🔒 **Zero Client Exposure**: Secure server-side architecture. Your Gemini API key is never exposed to the client or browser network logs.
* ⚡ **Fast & Responsive**: Built with Vite, React, TypeScript, and modern styling for a seamless user experience.
* 📦 **Production Ready**: Fully configurable for local development and cloud deployments (e.g., Vercel, Render).

---

## 🛠️ Tech Stack

* **Frontend**: React, TypeScript, Vite, Tailwind CSS
* **Backend / Server**: Node.js, Express / Custom Server (`server.ts`)
* **AI Integration**: Google Gemini API (`@google/genai` / `@google/generative-ai`)
* **Package Manager**: pnpm / npm / bun
